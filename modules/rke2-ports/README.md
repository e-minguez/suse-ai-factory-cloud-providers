# `modules/rke2-ports`

Port tables for RKE2 and the ingress controller, per node role. Each provider
module reshapes them into its own firewall or security group rules, so the open
ports are the same everywhere.

| Port name | Protocol and port | Open on |
|---|---|---|
| `kube_api` | tcp 6443 | control plane, API load balancer |
| `supervisor` | tcp 9345 | control plane, API load balancer |
| `etcd` | tcp 2379-2381 | control plane only |
| `kubelet` | tcp 10250 | every node |
| `vxlan` | udp 8472 | every node |
| `nodeport` | tcp 30000-32767 | every node |
| `http`, `https` | tcp 80, 443 | control plane, ingress load balancer (not with `ingress_controller = "none"`) |
| `ingress_ping` | tcp 8080 | control plane, only with `traefik` (health check) |

Workers, GPU or not, get no API, supervisor, etcd or ingress ports: agents only
dial out to the API. The port names are the `elemental-listener` label values on
load balancer objects ([conventions](../../docs/conventions.md#labels)).

## Inputs

| Name | Description | Type | Default | Required |
| ---- | ----------- | ---- | ------- | :------: |
| ingress\_controller | RKE2 ingress-controller setting. Controls which ingress ports appear in the matrix. | `string` | `"traefik"` | no |

## Outputs

| Name | Description |
| ---- | ----------- |
| control\_plane | Ports open on control-plane nodes: API, etcd, node ports and ingress. |
| control\_plane\_ingress | Ingress subset of control\_plane, the ports the ingress load balancer reaches. |
| lb\_api | Ports the API load balancer listens on and forwards. |
| lb\_ingress | Ports the ingress load balancer listens on; empty when there is no ingress controller. |
| lb\_ingress\_health | Health check per ingress LB listener (http, https): type tcp or http, target port and path. Empty without an ingress controller. |
| worker | Ports open on worker nodes, GPU or not: no API, supervisor, etcd or ingress. Agents only dial out to the API. |
