# `modules/image-factory`

Renders the shell script that builds the Elemental raw image on a build host.
The common steps are in `templates/factory-common.sh.tftpl`: install `podman`
and `curl` (plus `extra_packages`), run `elemental customize --type raw` in a
container with retries, locate the raw image, and write `state_dir/done`. The
provider supplies the platform steps as hook bodies.

## Hooks

Each hook is a Bash function body passed as a variable:

| Hook | Runs | Contract |
|---|---|---|
| `hook_pre_build` | after package install, before the check | install tools, open ports, fetch config |
| `hook_is_already_built` | before the build | return 0 when the output exists; the script then exits 0 without building |
| `hook_on_step` | at every step | `$1` step name, `$2` text; a failure is logged and ignored |
| `hook_deliver_raw` | after the build | `$1` is the raw image path; move it to its destination |
| `hook_on_exit` | from the EXIT trap | `$1` is the exit status |

The script logs to `log_file`, which defaults to the path `scripts/build-logs.sh`
follows. `script_stripped` is the comment-free script that ships in size-limited
`user_data`, and `script_hash` hashes exactly that text. Pass placeholders for
values derived from the build hash and substitute them after rendering, so the
hash stays an input of `build_hash` without depending on it (`extra_build_inputs`
in `modules/elemental-config`).

## Inputs

| Name | Description | Type | Default | Required |
| ---- | ----------- | ---- | ------- | :------: |
| build\_id | Build identifier (first 12 characters of build\_hash); written to the done marker and exposed to hooks as BUILD\_ID. | `string` | n/a | yes |
| config\_dir | Directory on the build host holding the Elemental config, including release\_manifest.yaml. Mounted at /config in the build container. | `string` | `"/var/lib/elemental-config"` | no |
| customize\_attempts | Attempts for elemental customize; registry errors mid-build are transient. | `number` | `3` | no |
| customize\_retry\_delay | Seconds to wait between customize attempts. | `number` | `60` | no |
| elemental\_image | OCI image that runs elemental3ctl customize. | `string` | n/a | yes |
| extra\_packages | Packages installed in addition to podman and curl. Each must provide a command of the same name; the script fails when one is missing afterwards. | `list(string)` | `[]` | no |
| hook\_deliver\_raw | Bash body of deliver\_raw. Receives $1 = path of the raw image and moves it to its destination. | `string` | `"return 0"` | no |
| hook\_is\_already\_built | Bash body of is\_already\_built. Return 0 when the output already exists; the script then skips the build and exits 0. | `string` | `"return 1"` | no |
| hook\_on\_exit | Bash body of on\_exit, run from the EXIT trap. Receives $1 = exit status. | `string` | `":"` | no |
| hook\_on\_step | Bash body of on\_step. Receives $1 = step name (prereqs, pre\_build, check, customize, locate, deliver, finished, failed) and $2 = text. | `string` | `":"` | no |
| hook\_pre\_build | Bash body of pre\_build, run after package install and before is\_already\_built (install tools, open ports, fetch config). | `string` | `":"` | no |
| log\_file | Build host file that receives all script output. scripts/build-logs.sh follows the default path. | `string` | `"/var/log/elemental-factory.log"` | no |
| state\_dir | Build host directory for the done marker (state\_dir/done contains build\_id after a successful build). | `string` | `"/var/lib/image-factory"` | no |

## Outputs

| Name | Description |
| ---- | ----------- |
| script | Complete build-host script: common steps with the hook bodies inlined. May contain whatever the hooks contain. |
| script\_hash | SHA-256 of script\_stripped. Hashes exactly what is delivered, so pass placeholders for values derived from the build hash and substitute them afterwards. |
| script\_stripped | The script without comment lines ("#!" lines kept) and with blank runs collapsed. |
